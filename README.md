# Report Fire

## Sobre o projeto

O Report Fire é um projeto acadêmico voltado ao desenvolvimento de uma aplicação para o registro de denúncias de queimadas. A proposta é oferecer uma interface simples para que o usuário informe ocorrências e forneça dados que ajudem na identificação do local.

## Objetivo

Desenvolver uma aplicação para registrar e organizar informações sobre queimadas, aplicando conhecimentos de Desenvolvimento de Sistemas, organização de código e gestão de projetos.

## Funcionalidades da interface

A versão atual apresenta quatro telas principais:

* **Login:** interface de acesso do usuário.
* **Criar Conta:** formulário para cadastro.
* **Tela Inicial:** página principal da aplicação.
* **Nova Denúncia:** formulário para informar uma ocorrência.

## Tecnologias utilizadas

* **HTML5:** estrutura da interface.
* **CSS3:** estilos e apresentação visual.
* **JavaScript:** interações da interface.
* **GitHub:** armazenamento e versionamento do código-fonte.
* **GitHub Pages:** publicação da interface.

## Estrutura dos arquivos

* `index.html` — contém a estrutura das telas.
* `style.css` — contém os estilos da aplicação.
* `script.js` — contém as interações e funcionalidades implementadas.
